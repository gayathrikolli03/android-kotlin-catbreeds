# Android Cat Breeds App

A Kotlin Android app built with Jetpack Compose that displays cat breeds using The Cat API.

## Features Implemented

- **All Breeds**: Fetches all available cat breeds using paginated API calls
- **Breed List**: Displays each breed with its name and description
- **Detail View**: Tap any breed to see a full detail screen with image and description
- **Search**: Filter breeds by name using the search bar

## Tech Used

- Jetpack Compose
- MVVM Architecture
- Retrofit for networking
- Coil for image loading
- LiveData + ViewModel
